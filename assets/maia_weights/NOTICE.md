# Origem dos pesos Maia

Os arquivos `maia-1100.pb.gz` a `maia-1900.pb.gz` neste diretório vêm,
sem modificação, da release oficial `v1.0` do repositório
[CSSLab/maia-chess](https://github.com/CSSLab/maia-chess):

```
https://github.com/CSSLab/maia-chess/releases/download/v1.0/maia-<rating>.pb.gz
```

redistribuição tomada neste projeto.
